# Ruby Slack design (summary of the Nov 18 outline)

**Principles:** one door in (DM) · Ruby holds it · next thing not everything · batched not constant ·
calm language ("still open") · one tap to act · confirm then remember · show progress.

**Workspace:** "Ruby HQ", Free plan, Pacific time. Roxy + Ruby only. DM is the only thing that pings; 9 channels muted:
#make-ready-vendors #residents #collections #inspections #inbox-emails #dar-notes #supplies #wins #ruby-log.

**Rhythm (Mon-Fri):** 7:00 Top 3 · 11:00 and 2:00 check-ins · 4:00 DAR prompt · 5:00 shutdown.
Mon/Thu 11:00 stuck units · Fri 5:00 weekly wins · 7th delinquency cycle · first business day inspections.

**Top 3 order:** hard deadlines → tomorrow's move-ins with gaps → starred carry-overs → unblockers → by due time (📌 pins first).

**Quiet hours:** Ruby starts conversations Mon-Fri 7:00-17:30. Only three things break that, 6:00-21:00, never overnight:
items marked urgent, next-morning move-in gaps, next-business-day hard legal deadlines. `/quiet N` and the overwhelm pause hold everything else.

**Follow-up:** surface in check-in → once more at the next → 5 PM moves to tomorrow starred → no further pings.

**Actions:** emoji (✅ ⏰ 📌 🔁 🚨 ❌ 👀) and buttons (Done / Later today / Tomorrow / More…); confirmations Approve / Edit / Cancel;
Undo for 24h. Drafts post as a bare message (long-press to copy) followed by Shorter / Warmer / More formal / Mark as sent.

**Privacy:** unit # + first name only, no balances in channels.

**Open items:** Free vs Pro, overwhelm pause length, weekly Robin reports, profile photo, company email-paste policy, sample DARs/templates.
